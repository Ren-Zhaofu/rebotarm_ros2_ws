# Omnipicker CAN 协议

当前硬件使用 11 位标准 CAN ID `0x07`，经典 CAN 数据帧长度为 8 字节。

## 控制帧

| 字节 | 含义 | 范围 |
| --- | --- | --- |
| 0 | 保留 | `0x00` |
| 1 | 目标位置 | `0x00` 全关，`0xFF` 全开 |
| 2 | 速度 | `0x00` ~ `0xFF` |
| 3 | 力度 | `0x00` ~ `0xFF` |
| 4 | 加速度 | `0x00` ~ `0xFF` |
| 5 | 减速度 | `0x00` ~ `0xFF` |
| 6~7 | 保留 | `0x00` |

SDK 接口使用 `[0.0, 1.0]` 归一化值，并按四舍五入映射到一个字节。超出范围、非有限值和超出 11 位范围的 CAN ID 会被拒绝，不做静默截断。

## 反馈帧

SDK 按厂商资料解析前五个字节：故障码、状态、位置、速度、力度。后三个字节保留在 `State::raw_data` 中。默认反馈 ID 与命令 ID 相同，均为 `0x07`；若实际固件使用不同反馈 ID，可在 `Gripper::connect()` 中显式传入。
