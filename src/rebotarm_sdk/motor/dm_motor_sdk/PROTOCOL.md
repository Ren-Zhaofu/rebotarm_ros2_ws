# DM 电机协议摘要

## 事实来源和边界

本包依据以下资料重新实现，没有复制参考工程源码：

- `reference/dm_motor/openarm_motor` 中可观察到的协议行为；
- 《DM-J4310-2EC V1.2 减速电机使用说明书》，日期 2025-10-22；
- reBotArm 实机上 `0x01..0x07` 与 `0x11..0x17` 的抓帧结果。

参考 SDK 目录没有发现许可证，因此最终包采用独立接口和实现。J4310 手册是
J4310-2EC 型号的优先事实来源；其他型号的默认 MIT 映射量程来自参考实现，接入真机时
应读取电机的 PMAX、VMAX、TMAX 寄存器进行复核。

2026-07-26 的 reBotArm 真机只读结果为：1–3 号电机
PMAX/VMAX/TMAX=`12.5/10/28`，4–7 号电机为 `12.5/30/10`；七个电机的
CTRL_MODE 均为 `2`（位置速度模式）。

当前 `SocketCan` 仅处理标准 11 位经典 CAN 帧。手册指出波特率高于 1 Mbps 时电机反馈
会切换为 CAN FD，因此本首版只支持不高于 1 Mbps 的经典 CAN 配置。

## CAN 基本约定

- 标准帧，默认 1 Mbps；
- 电机接收 ID 由 ESC_ID/CAN ID 配置；
- 反馈 ID 由 MST_ID/Master ID 配置；
- 管理帧使用 `0x7FF`；
- 位置速度、速度、力位模式的控制 ID 分别是 `ID+0x100`、`ID+0x200`、
  `ID+0x300`；
- 所有多字节 float、uint16 和 uint32 参数均低字节在前；
- 反馈是问询式的，电机接到匹配命令后返回统一状态帧。

## 状态命令

状态命令使用电机命令 ID，D0-D6 均为 `FF`：

| 操作 | D7 |
|---|---:|
| 清除错误 | `FB` |
| 使能 | `FC` |
| 失能 | `FD` |
| 保存当前位置为零点 | `FE` |

`FE` 会改变零位；不能把它当成普通停止命令。

## 控制命令

MIT 帧使用电机命令 ID，共 8 字节：

```text
P[15:8] P[7:0] V[11:4] V[3:0]|KP[11:8] KP[7:0]
KD[11:4] KD[3:0]|T[11:8] T[7:0]
```

- P：16 位线性映射；
- V、KP、KD、T：12 位线性映射；
- KP 范围 `[0,500]`；
- KD 范围 `[0,5]`；
- P、V、T 范围由 PMAX、VMAX、TMAX 决定；
- 手册明确指出位置控制时 KD 不能为零。

位置速度帧使用 `0x100+ID`：

```text
float32 position | float32 maximum_velocity
```

速度帧使用 `0x200+ID`：

```text
float32 velocity
```

力位混控使用 `0x300+ID`：

```text
float32 position | uint16(velocity*100) | uint16(current_ratio*10000)
```

速度限制为 `0..100 rad/s`，电流是最大相电流的 `0..1` 标幺值。

## 反馈帧

反馈 ID 为配置的 Master ID，固定 8 字节：

```text
D0: motor_id[3:0] | status[7:4]
D1-D2: position uint16
D3-D4高半字节: velocity uint12
D4低半字节-D5: effort uint12
D6: MOS 温度 °C
D7: 转子/线圈温度 °C
```

状态高半字节：

| 值 | 含义 |
|---:|---|
| `0` | 失能 |
| `1` | 使能 |
| `3` | 输出轴校准异常 |
| `4` | 输出传感器异常 |
| `5` | 电机编码器校准异常 |
| `8` | 过压 |
| `9` | 欠压 |
| `A` | 过流 |
| `B` | MOS 过温 |
| `C` | 电机线圈过温 |
| `D` | 通讯丢失 |
| `E` | 过载 |

## 管理帧

| 操作 | ID | 数据 | DLC |
|---|---:|---|---:|
| 刷新状态 | `7FF` | `ID_L ID_H CC 00 00 00 00 00` | 8 |
| 读参数 | `7FF` | `ID_L ID_H 33 RID` | 4 |
| 写参数 | `7FF` | `ID_L ID_H 55 RID DATA[0..3]` | 8 |
| 保存参数 | `7FF` | `ID_L ID_H AA 01` | 4 |

读写应答从电机反馈 ID 返回。D4-D7 是 little-endian `float32` 或 `uint32`。

整数寄存器包括 MST_ID、ESC_ID、TIMEOUT、CTRL_MODE、硬件/软件/序列版本、
极对数、CAN 波特率、子版本和 Boot 版本；其余已知数值寄存器按 float32 处理。

SDK 根据 J4310 V1.2 手册拒绝写只读寄存器。可写地址为 `0x00..0x0A` 和
`0x15..0x23`。

## 关键安全约束

- 保存参数只在失能状态生效，最长约 30 ms；
- Flash 擦写寿命约一万次，禁止周期性保存；
- 修改控制模式会清零位置、速度、力矩、KP 和 KD 命令；
- 切换到位置类模式前应读取精确位置，并尽量保证零速；
- CAN 修改波特率时不能在多电机总线上盲目执行；
- 电机上电默认为失能；
- MIT 力矩模式即使给定很小力矩，空载电机也可能加速至最高转速；
- 设零、参数写入、参数保存和模式切换必须由上层双重安全门禁保护。
